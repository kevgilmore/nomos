# Implement

Read `AGENTS.md`, identify acceptance criteria, and compose the feature from
`@nomos/ui`, shared layout, and page patterns. Add reusable pieces to
`platform/`, not an app. Add or update permanent tests before handing off.

Do not mark the task complete. Run deterministic checks, then hand the original
request, acceptance criteria, changed paths, and check results to the parent
agent for independent verification.
